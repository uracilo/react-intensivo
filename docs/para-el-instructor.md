# Para el instructor

## Ritmo sugerido (40 h)

| Bloque | Horas | Foco |
|--------|------:|------|
| Día 0 | 4–6 | HTML/CSS/JS + contraste React |
| Día 1 | 8 | Vite, props, tipos TaskFlow |
| Día 2 | 8 | useState + formularios |
| Día 3 | 8 | fetch + hooks |
| Día 4 | 8 | Router + CRUD |
| Día 5 | 8 | JWT + API Java |

Si el grupo va lento: acortá Día 0 a 3 h (solo lista add/toggle) y mové teoría jQuery a 10 minutos al inicio del Día 1.

## Checkpoints por día

- **D0:** Agregar / marcar / borrar sin recargar.
- **D1:** Se ven 5 cards seed con badges.
- **D2:** Validación título 3–120; lista se actualiza al agregar.
- **D3:** Spinner → resultados; filtros cambian la lista.
- **D4:** Navegar dashboard → proyecto → tarea → editar.
- **D5:** Login ana/ana123; CRUD con o sin API.

## Cómo usar las demos

Cada carpeta en `demos/` es el **resultado final** del día.  
Las guías (`docs/guia-dia-N.md`) enseñan a **reconstruirla**.

En clase: proyectá la demo, después codeáis juntos siguiendo la guía.

## Tip

No introduzcas MUI ni librerías de UI: el CSS compartido refuerza lo del Día 0.
